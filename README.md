# Inventario-js

## Objetivo

Inventario-js es una aplicación de consola desarrollada en JavaScript (Node.js) que simula un sistema de gestión de inventario para Rietman y Cía. - Estación de servicio bandera YPF. El sistema permite administrar el stock de tres sectores operativos: Playa de Líquidos, Playa de GNC, Tienda Full. El objetivo del proyecto es aplicar fundamentos de programación (análisis de problema, diagramas de flujo, modularización, estructuras de datos básicas y validaciones) antes de incorporar tecnologías más avanzadas.
